# 🎬 Movie Recommender System

## 📌 Overview
A machine learning-based movie recommendation system that suggests similar movies using content-based filtering.

## 🚀 Features
- Recommend similar movies
- Fetch movie posters using TMDB API
- FastAPI backend
- Streamlit frontend

## 🛠 Tech Stack
- Python
- Pandas, Scikit-learn
- FastAPI
- Streamlit
